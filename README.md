# KlanLabs website

The klanlabs.com site, rebuilt in code (previously WordPress).

- **Stack:** TanStack Start, React 19, Vite, Tailwind 4 — the Lovable default stack.
- **Run locally:** `bun install` (or `npm install`), then `npm run dev`.
- **Copy:** every word lives in `src/content/` (`solutions.ts` for the five Solutions pages, `site.ts` for everything else).
- **Styles:** `src/styles/kl.css`.
- **Contact form:** posts to FormSubmit for `hello@klanlabs.com` — the first submission sends an activation email that must be clicked once.
